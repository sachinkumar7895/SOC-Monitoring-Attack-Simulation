# SOC Monitoring & Cybersecurity Attack Simulation

## Project Overview
This project demonstrates practical cybersecurity skills through an isolated virtual lab environment using Kali Linux and Metasploitable 2.

The project focuses on network reconnaissance, web application security analysis, network traffic monitoring, and basic SOC investigation.

## Objectives
- Understand network reconnaissance.
- Identify open ports and running services.
- Analyze web server technologies.
- Understand SQL Injection security concepts.
- Monitor network traffic.
- Analyze Apache access and error logs.

## Tools & Technologies
- Kali Linux
- Metasploitable 2
- Oracle VirtualBox
- Nmap
- WhatWeb
- DVWA
- Wireshark
- Apache Access & Error Logs

## Practical Implementation

### 1. Network Reconnaissance
Used Nmap to identify active hosts, open ports, and running services.

### 2. Web Server Fingerprinting
Used WhatWeb to identify web server technologies and configurations.

### 3. Web Application Security Analysis
Compared DVWA Low and High security levels to understand SQL Injection concepts.

### 4. Network Traffic Analysis
Used Wireshark to capture and analyze HTTP and TCP traffic.

### 5. SOC Monitoring & Log Analysis
Analyzed Apache access and error logs to identify HTTP requests, 404 errors, and reconnaissance-related activity.

## Key Findings
- Identified 23 open TCP ports.
- Detected outdated web server technologies.
- Observed HTTP 200 and 404 responses.
- Analyzed TCP communication.
- Identified Nmap-related activity in Apache error logs.

## Lab Environment
- Virtualization: Oracle VirtualBox
- Testing Machine: Kali Linux
- Target Machine: Metasploitable 2
- Network: Isolated Internal Network
